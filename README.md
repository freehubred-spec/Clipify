# Clipify - Fast & Easy Video Editor

Modern browser-based video editor for YouTubers, Reels creators, Faceless content creators and everyone.

## Features (MVP v1)

- Upload multiple videos
- Timeline with clips
- Video preview + playback controls
- Speed control (0.5x – 2x)
- Text overlays (draggable)
- Filters (B&W, Sepia, Contrast, Bright, Vibrant)
- Brightness / Contrast / Saturate adjustments
- Aspect ratio presets (16:9, 9:16, 1:1, 4:5)
- Audio upload support
- Export / Download
- Dark modern UI matching Clipify branding

## How to Run

### Option 1: Local
1. Download this folder
2. Open `index.html` in Chrome / Edge / Firefox

### Option 2: GitHub + Free Hosting (Recommended)

1. Create a new repository on GitHub named `clipify`
2. Upload all files (`index.html`, `style.css`, `app.js`, `README.md`)
3. Go to **Settings → Pages**
4. Source: Deploy from branch `main`
5. Your site will be live at: `https://yourusername.github.io/clipify`

### Option 3: Vercel / Netlify
- Just drag & drop the folder on [vercel.com](https://vercel.com) or [netlify.com](https://netlify.com)
- Instant free hosting with custom domain support

## Tech Stack
- Pure HTML + CSS + JavaScript (no framework)
- No backend required
- Works completely offline after loading
